# Interactive object examples

Each `##` heading is a button label. The `###` heading is the object's name, and the table contains its properties. You can edit these words and values, add rows, or copy a whole example to add another button. These are illustrative examples; they do not connect to a database.

## A device

### Greenhouse sensor

| Property | Value |
| --- | --- |
| type | sensor |
| temperature | 24 |
| online | true |
| location | { greenhouse: "A" } |
